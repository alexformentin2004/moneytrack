# MoneyTrack V1
App PWA di finanza personale con tema Premium Dark, salvataggio IndexedDB e backup JSON/CSV.

## Pubblicazione
Carica `index.html`, `manifest.webmanifest`, `icon.svg` e `sw.js` nella root di un repository GitHub e abilita GitHub Pages (Deploy from branch, main, root). Apri l'URL HTTPS risultante e aggiungilo alla Home di iPhone con Safari.

## Funzioni
Conti multipli, saldi iniziali, entrate, spese, trasferimenti, categorie, modifica/eliminazione movimenti, ricorrenze, statistiche, obiettivi, backup JSON e CSV.

## Note
Le ricorrenze vengono elaborate quando l'app viene aperta. I dati risiedono nel browser/dispositivo, non in GitHub. Esporta regolarmente il backup JSON. Gli obiettivi sono contatori manuali e non spostano fondi tra conti.
